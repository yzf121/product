## 1. 项目概述

### 1.1 项目简介

**AI 助手平台**是一个基于 **SAP CAP (Cloud Application Programming)** 框架和 **SAP UI5 Freestyle** 前端技术构建的企业级 AI 智能助手应用。该平台集成了**阿里云百炼（DashScope）** 大语言模型 API，为 SAP 开发人员提供多种 AI 辅助工具，帮助提升开发效率。

### 1.2 核心能力

| 功能模块 | 描述 |
|---------|------|
| **ABAP Clean Core 助手** | 帮助将传统 ABAP 代码重构为云就绪（Cloud-Ready）代码 |
| **CPI 集成助手** | SAP CPI Integration Suite 开发指导 |
| **功能文档生成** | 自动生成功能规格说明文档 |
| **技术文档生成** | 自动生成技术设计文档 |
| **代码审查助手** | 智能代码质量检查 |
| **单元测试生成** | 自动生成 ABAP 单元测试代码 |
| **流程图生成** | AI 驱动的 Mermaid 流程图/架构图生成工具 |
| **文件上传分析** | 上传 PDF、Word、Excel 等文档供 AI 分析 |

### 1.3 技术特性

- ✅ **流式响应 (SSE)**: 支持实时流式 AI 响应，提升用户体验
- ✅ **多 AI 助手切换**: 单一平台支持多个专业领域 AI 助手
- ✅ **会话管理**: 支持多轮对话，智能会话存储策略
- ✅ **文件上传**: 支持上传 PDF、Word、Excel 等文档供 AI 分析
- ✅ **Markdown 渲染**: 支持富文本、代码高亮显示
- ✅ **国际化**: 支持中文（zh_CN）和英文（en）
- ✅ **响应式设计**: 适配桌面、平板、手机多端设备
- ✅ **SAP BTP 部署**: 支持一键部署到 SAP Business Technology Platform
- ✅ **端口自动切换**: 开发时自动检测并使用可用端口

## 5. 后端服务说明

### 5.1 服务架构

后端服务基于 SAP CAP 框架，包含两部分：

1. **CDS 服务定义** (`srv/chat-service.cds`)
2. **自定义服务器** (`srv/server.js`)

### 5.2 CDS 服务定义

```cds
// srv/chat-service.cds
service ChatService @(path: '/api/chat') {
    action sendMessage(message: String, sessionId: String) returns String;
}
```

这是一个备用的非流式消息发送接口。

### 5.3 自定义服务器 (server.js)

`server.js` 是项目的核心后端文件，提供以下功能：

#### 5.3.1 AI 助手类型映射

```javascript
const AI_APP_ID_MAP = {
    'abap-clean-core': process.env.DASHSCOPE_APP_ID_ABAP || process.env.DASHSCOPE_APP_ID,
    'cpi': process.env.DASHSCOPE_APP_ID_CPI,
    'func-doc': process.env.DASHSCOPE_APP_ID_FUNC_DOC,
    'tech-doc': process.env.DASHSCOPE_APP_ID_TECH_DOC,
    'code-review': process.env.DASHSCOPE_APP_ID_CODE_REVIEW,
    'unit-test': process.env.DASHSCOPE_APP_ID_UNIT_TEST,
    'diagram': process.env.DASHSCOPE_APP_ID_DIAGRAM
};
```

每个 AI 助手对应阿里云百炼中的不同应用 ID，实现专业化分工。
未配置的 `aiType` 会回退到默认应用 ID（`DASHSCOPE_APP_ID` 或 `DASHSCOPE_APP_ID_ABAP`）。

#### 5.3.2 流式响应端点

**端点**: `POST /api/chat/stream`

**请求体**:
```json
{
    "message": "用户输入的消息",
    "sessionId": "会话ID（可选）",
    "aiType": "AI类型（可选，默认 abap-clean-core）",
    "messages": [{"role": "user/assistant", "content": "..."}],
    "sessionInfo": {
        "createdAt": "2025-01-01T00:00:00Z",
        "roundCount": 5
    },
    "sessionFileIds": ["file_session_xxx"]
}
```

**响应**: Server-Sent Events (SSE) 格式

```
data: {"text": "部分响应内容", "sessionId": "xxx"}

data: {"text": "继续响应...", "sessionId": "xxx"}

data: [DONE]
```

#### 5.3.3 会话管理策略

```javascript
const SESSION_CONFIG = {
    MAX_ROUNDS: 50,        // 百炼 API 限制：最多 50 轮
    EXPIRE_HOURS: 1,       // 百炼 API 限制：1 小时过期
    FALLBACK_ROUNDS: 10    // 降级时使用的历史轮数
};

// 文件上传配置
const FILE_UPLOAD_CONFIG = {
    MAX_FILE_SIZE: 50 * 1024 * 1024, // 50MB
    MAX_FILES_PER_SESSION: 5,        // 单会话最多5个文件
    ALLOWED_EXTENSIONS: ['.pdf', '.doc', '.docx', '.txt', '.md', '.json', '.xml', '.csv', '.xlsx', '.xls', '.ppt', '.pptx'],
    PARSE_TIMEOUT: 120000,           // 解析超时120秒
    POLL_INTERVAL: 2000              // 轮询间隔2秒
};
```

**混合策略**：
1. 优先使用 `session_id`（云端存储上下文，节省 token）
2. 超过 50 轮或 1 小时后，自动降级到 `messages` 模式（发送本地历史）
3. 新对话时只发送当前消息

#### 5.3.4 端口自动切换

```javascript
async function findAvailablePort(startPort, maxAttempts = 10) {
    for (let i = 0; i < maxAttempts; i++) {
        const port = startPort + i;
        const available = await isPortAvailable(port);
        if (available) return port;
    }
    throw new Error('无法找到可用端口');
}
```

开发时如果默认端口 4004 被占用，会自动尝试 4005、4006 等后续端口。

### 7.2 CDS 配置 (.cdsrc.json)

```json
{
    "requires": {
```

- `db.kind`: 数据库类型（开发时使用 SQLite）
- `server.impl`: 指定自定义服务器入口

### 7.3 MTA 部署配置 (mta.yaml)

MTA (Multi-Target Application) 描述符定义了云端部署结构：

**模块 (Modules)**:
- `abap-clean-core-ai-fiori-new-srv`: Node.js 后端服务
- `comaiassistantaichatapp`: HTML5 前端应用

## 10. API 接口文档

### 10.1 流式聊天接口

**接口**: `POST /api/chat/stream`

**描述**: 发送消息给 AI 助手，接收流式响应

**请求头**:
```
Content-Type: application/json
```

**请求体**:
```json
{
    "message": "string (必需) - 用户消息内容",
    "aiType": "string (可选) - AI 助手类型，默认 abap-clean-core",
    "sessionId": "string (可选) - 会话 ID",
    "messages": "array (可选) - 历史消息数组",
    "sessionInfo": {
        "createdAt": "string - 会话创建时间",
        "roundCount": "number - 当前轮次"
    },
    "sessionFileIds": "array (可选) - 会话文件 ID 列表"
}
```

**支持的 aiType 值**:
- `abap-clean-core`
- `cpi`
- `func-doc`
- `tech-doc`
- `code-review`
- `unit-test`
- `diagram`

**响应**: `text/event-stream` (SSE)

```
data: {"text": "AI 响应文本片段", "sessionId": "新的会话ID"}

data: {"text": "继续响应..."}

data: [DONE]
```

**错误响应**:
```
data: {"error": "错误信息"}
```

### 10.2 CDS OData 服务

**服务路径**: `/api/chat`

**可用操作**:
- `sendMessage(message, sessionId)`: 发送消息（非流式，备用）

## 13. 常见问题

### Q1: 启动时提示端口被占用？

**A**: 应用会自动尝试下一个可用端口。检查终端输出，会显示实际使用的端口号。

### Q2: AI 响应为空或报错？

**A**: 
1. 检查 `.env` 文件中的 API Key 是否正确
2. 确认对应 AI 类型的 App ID 已配置
3. 查看终端日志了解详细错误信息

### Q3: 如何添加新的 AI 助手？

**A**:
1. 在阿里云百炼创建新应用，获取 App ID
2. 在 `.env` 中添加新的环境变量
3. 在 `server.js` 的 `AI_APP_ID_MAP` 中添加映射
4. 在 `Home.view.xml` 中添加新的磁贴
5. 在 i18n 文件中添加对应的标题和描述

### Q4: 流程图不能正确渲染？

**A**:
1. 检查 Mermaid 语法是否正确
2. 使用「修复输出格式」按钮尝试自动修复
3. 手动编辑 Mermaid 代码后点击「渲染」

### Q5: 如何自定义样式？

**A**: 编辑 `app/ai-chat-gui/webapp/css/style.css` 文件，样式会自动应用。

### Q6: 对话历史丢失？

**A**: 对话历史存储在浏览器 localStorage 中：
- 清除浏览器数据会丢失历史
- 最多保存 100 条对话
- 不同浏览器/设备间不共享
