## 2. CDS 运行时配置 (.cdsrc.json)

### 文件位置
- 根目录: `.cdsrc.json`

### 配置内容

```json
{
    "requires": {
        "db": {
            "kind": "sql"
        }
    },
    "server": {
        "impl": "./srv/server.js"
    }
}
```

### 配置项说明

| 配置 | 说明 |
|-----|------|
| `requires.db.kind` | 数据库类型，开发时使用 SQLite（由 `@cap-js/sqlite` 提供） |
| `server.impl` | 自定义服务器入口文件路径，指向 `srv/server.js`，用于实现流式响应和文件上传等自定义功能 |

> **重要**: `server.impl` 配置使 CDS 框架使用自定义的 `server.js` 作为服务器入口，而非默认的 CDS 服务器。这是实现 SSE 流式响应和文件上传功能的关键配置。

### 扩展配置

如需添加更多配置：

```json
{
    "requires": {
        "db": {
            "kind": "sql"
        },
        "[production]": {
            "db": {
                "kind": "hana"
            }
        }
    },
    "server": {
        "impl": "./srv/server.js"
    },
    "log": {
        "levels": {
            "cds": "debug"
        }
    }
}
```

## 3. MTA 部署配置 (mta.yaml)

### 文件位置
- 根目录: `mta.yaml`

### 结构概览

```yaml
_schema-version: 3.3.0
ID: abap-clean-core-ai-fiori-new
description: AI 助手平台 - 基于阿里云百炼的 ABAP Clean Core Helper
version: 1.4.3

modules:          # 应用模块
  - name: ...     # 后端服务
  - name: ...     # 前端应用
  - name: ...     # 部署器

resources:        # 服务资源
  - name: ...     # XSUAA
  - name: ...     # Destination
  - name: ...     # HTML5 Repository

parameters:       # 全局参数
  deploy_mode: html5-repo
```

### 模块说明

#### 后端服务模块

```yaml
- name: abap-clean-core-ai-fiori-new-srv
  type: nodejs
  path: gen/srv
  requires:
    - name: abap-clean-core-ai-fiori-new-auth
  provides:
    - name: srv-api
      properties:
        srv-url: http://${routes/0/route}
  parameters:
    buildpack: nodejs_buildpack
    instances: 1          # 实例数量
    memory: 256M          # 内存配额
    routes:
      - route: abap-clean-core-ai-fiori-new-srv.apps.internal  # 固定路由
  build-parameters:
    builder: npm
```

#### 前端应用模块

```yaml
- name: comaiassistantaichatapp
  type: html5
  path: app/ai-chat-gui
  build-parameters:
    build-result: dist
    builder: custom
    commands:
      - npm install
      - npm run build:cf
    supported-platforms: []
```

#### HTML5 部署器

```yaml
- name: abap-clean-core-ai-fiori-new-app-deployer
  type: com.sap.application.content
  path: gen
  requires:
    - name: abap-clean-core-ai-fiori-new-html5-repo-host

    build-result: app/

      - artifacts:
```

## 4. 安全配置 (xs-security.json)

### 文件位置
- 根目录: `xs-security.json`

### 配置内容

```json
{
    "xsappname": "abap-clean-core-ai-fiori-new",
    "tenant-mode": "dedicated",
    "scopes": [
        {
            "name": "$XSAPPNAME.user",
            "description": "User access"
        }
    ],
    "attributes": [],
    "role-templates": [
        {
            "name": "User",
            "description": "User role",
            "scope-references": [
                "$XSAPPNAME.user"
            ]
        }
    ],
    "role-collections": [
        {
            "name": "AIChat_User",
            "description": "AI Chat Application User",
            "role-template-references": [
                "$XSAPPNAME.User"
            ]
        }
    ],
    "oauth2-configuration": {
        "redirect-uris": [
            "https://*.cfapps.*.hana.ondemand.com/**",
            "https://*.launchpad.cfapps.*.hana.ondemand.com/**",
            "https://*.cfapps.*.platform.sapcloud.cn/**",
            "https://*.launchpad.cfapps.*.platform.sapcloud.cn/**"
        ]
    }
}
```

### 配置项说明

| 配置 | 说明 |
|-----|------|
| `xsappname` | 应用名称，必须唯一 |
| `tenant-mode` | 租户模式：dedicated（专用）或 shared（共享） |
| `scopes` | 权限范围定义 |
| `role-templates` | 角色模板定义 |
| `role-collections` | 角色集合（用于分配给用户） |
| `oauth2-configuration` | OAuth2 配置，包括重定向 URI |

```yaml
  name: com.ai.assistant.aichatapp

  customMiddleware:
    - name: fiori-tools-proxy
      afterMiddleware: compression
      configuration:
        ignoreCertErrors: false
        ui5:
          path:
            - /resources
            - /test-resources
          url: https://sapui5.hana.ondemand.com
        backend:
          - path: /api
            url: http://localhost:4004

    - name: fiori-tools-appreload
      afterMiddleware: compression
      configuration:
        port: 35729
        path: webapp
        delay: 300

    - name: fiori-tools-preview
      afterMiddleware: fiori-tools-appreload
      configuration:
        flp:
          theme: sap_horizon

  resources:
    excludes:
      - "webapp/lib/highlight.min.js"
      - "com/ai/assistant/aichatapp/lib/highlight.min.js"

  componentPreload:
    excludes:
      - "com/ai/assistant/aichatapp/lib/highlight.min.js"
      - "**/highlight.min.js"
```

## 9. 应用路由配置 (xs-app.json)

### 文件位置
- `app/ai-chat-gui/xs-app.json`

### 配置内容

```json
{
    "welcomeFile": "/index.html",
    "authenticationMethod": "route",
    "routes": [
        {
            "source": "^/resources/(.*)$",
            "target": "/resources/$1",
            "authenticationType": "none",
            "destination": "ui5"
        },
        {
            "source": "^/test-resources/(.*)$",
            "target": "/test-resources/$1",
            "authenticationType": "none",
            "destination": "ui5"
        },
        {
            "source": "^/api/(.*)$",
            "target": "/api/$1",
            "authenticationType": "xsuaa",
            "destination": "srv-api"
        },
        {
            "source": "^(.*)$",
            "target": "$1",
            "service": "html5-apps-repo-rt",
            "authenticationType": "xsuaa"
        }
    ]
}
```

### 路由规则说明

| 规则 | 描述 |
|-----|------|
| `/api/*` | API 请求转发到后端服务 |
| `*` | 静态资源从 HTML5 仓库获取 |

## 10. 配置最佳实践

### 开发环境 vs 生产环境

| 配置项 | 开发环境 | 生产环境 |
|-------|---------|---------|
| 数据库 | SQLite | HANA / 无 |
| 认证 | 无 | XSUAA |
| 日志级别 | debug | info |
| 端口 | 4004 | 自动分配 |

### 配置优先级

1. 命令行参数
2. 环境变量 (`.env`)
3. 配置文件 (`.cdsrc.json`)
4. 默认值

### 敏感信息处理

- ✅ 使用环境变量存储敏感信息
- ✅ 用下文示例新建 `.env`（如需可自行维护 `.env.example` 模板）
- ✅ 将 `.env` 添加到 `.gitignore`
- ❌ 不要在代码中硬编码密钥
- ❌ 不要在日志中打印完整密钥
