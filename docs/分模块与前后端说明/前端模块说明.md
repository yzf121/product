#### 2. 会话管理策略

系统采用混合会话策略，与服务端保持一致：

```javascript
_SESSION_CONFIG: {
    MAX_ROUNDS: 50,        // 百炼 API 限制：最多50轮
    EXPIRE_HOURS: 1,       // 百炼 API 限制：1小时过期
    FALLBACK_ROUNDS: 10    // 降级时使用的历史轮数
}
```

- **优先模式**: 使用 `session_id`（云端存储上下文，节省 token）
- **降级模式**: 超过 50 轮或 1 小时后，自动切换到 `messages` 模式
- **本地存储**: 对话历史保存在 localStorage

## 🌐 国际化 (i18n)

### 支持的语言

| 语言 | 文件 | 区域设置 |
|-----|------|---------|
| 英文（默认） | `i18n.properties` | `""` |
| 英文 | `i18n_en.properties` | `en` |
| 简体中文 | `i18n_zh_CN.properties` | `zh_CN` |

### 关键 i18n 键

#### 通用
- `appTitle` - 应用标题
- `appDescription` - 应用描述

#### 首页
- `welcomeHomeTitle` - 欢迎标题
- `welcomeHomeSubtitle` - 欢迎副标题
- `aiAssistantsCategory` - AI 助手分类
- `toolsCategory` - 工具分类

#### AI 助手
- `abapCleanCoreTitle` / `abapCleanCoreDesc`
- `cpiAiTitle` / `cpiAiDesc`
- `funcDocAiTitle` / `funcDocAiDesc`
- `techDocAiTitle` / `techDocAiDesc`
- `codeReviewTitle` / `codeReviewDesc`
- `unitTestTitle` / `unitTestDesc`

#### 聊天页面
- `welcomeTitle_{aiType}` - 欢迎标题
- `welcomeMessage_{aiType}` - 欢迎消息
- `newConversation` - 新建对话
- `sendMessage` - 发送消息

#### 流程图页面
- `diagramInputTitle` - 页面标题
- `diagramInputPlaceholder` - 描述占位
- `generateDiagram` - 生成按钮
- `renderMermaid` - 渲染按钮
- `downloadPNG` / `downloadSVG` - 导出按钮

## 📊 数据模型

### chat 模型

定义在 `manifest.json` 中：

```json
{
    "type": "sap.ui.model.json.JSONModel",
    "settings": {
        "data": {
            "messages": [],
            "conversations": [],
            "currentConversationId": null,
            "attachments": [],
            "inputValue": "",
            "isLoading": false,
            "sidebarExpanded": true
        }
    }
}
```

### 对话数据结构

```javascript
{
    id: "conv_1234567890",       // UUID 格式
    title: "对话标题",           // 首条消息前 20 字符或"新对话"
    aiType: "abap-clean-core",   // AI 助手类型
    lastUpdate: "2025-01-08 10:00", // 最后更新时间
    sessionId: "xxx",            // 百炼 session_id（首次收到时保存）
    messages: [
        {
            id: "msg_1",         // UUID 格式
            role: "user",        // user | assistant
            content: "消息内容",
            timestamp: "2025-01-08T10:00:00Z"  // ISO 8601 格式
        }
    ],
    sessionInfo: {
        createdAt: "2025-01-08T10:00:00Z",  // 会话创建时间
        roundCount: 5                        // 当前轮次（每轮对话完成时累加）
    },
    attachments: [               // 附件数组
        { /* 附件对象 */ }
    ]
}
```

### 附件数据结构

```javascript
{
    id: "att_1234567890",        // UUID 格式
    file: File,                  // 原始文件对象（处理时会提取）
    fileName: "document.pdf",    // 原始文件名
    fileSize: 1024000,           // 文件大小（字节）
    fileExt: "pdf",              // 文件扩展名（不含点）
    status: "parsed",            // parsing | parsed | error
    parsedText: "xxxx",          // 最核心功能所在：文档已经被转换成字符串
    progress: 100,               // 进度
    message: "已在本地解析"        // 状态描述信息
}
```

## 🔧 第三方库集成

### 库列表

| 库名称 | 版本 | 用途 | 加载方式 |
|-------|------|------|---------|
| marked.js | latest | Markdown 解析 | Local（index.html） |
| highlight.js | latest | 代码语法高亮 | Local（index.html） |
| mermaid.js | latest | 流程图渲染 | 动态加载（Diagram.controller.js） |
| Draw.io Embed | - | 图表编辑 | iframe（embed.diagrams.net） |

### 加载方式

- `marked.js` / `highlight.js`：在 `index.html` 中从 `lib/` 目录加载  
- `mermaid.js`：在 `Diagram.controller.js` 中通过 `sap.ui.require.toUrl` 动态加载 `lib/mermaid.min.js`

```html
<!-- Marked.js -->
<script src="lib/marked.min.js"></script>

<!-- Highlight.js -->
<link rel="stylesheet" href="css/highlight-github-dark.min.css">
<script src="lib/highlight.min.js"></script>
```

```javascript
// Diagram.controller.js - 动态加载 Mermaid
_initMermaid: function () {
    if (typeof mermaid !== "undefined") {
        this._configureMermaid();
        return;
    }
    
    var script = document.createElement("script");
    script.src = sap.ui.require.toUrl("com/ai/assistant/aichatapp/lib/mermaid.min.js");
    script.onload = function () {
        that._configureMermaid();
    };
    document.head.appendChild(script);
}
```

### Mermaid 配置

```javascript
mermaid.initialize({
```

## 📝 开发指南

### 添加新的 AI 助手

1. **在 Home.view.xml 添加磁贴**:
```xml
<GenericTile
    header="{i18n>newAssistantTitle}"
    subheader="{i18n>newAssistantSubtitle}"
    class="aiTile"
    press="onTilePress">
    <tileContent>
        <TileContent>
            <content>
                <ImageContent src="sap-icon://icon-name" />
            </content>
        </TileContent>
    </tileContent>
    <customData>
        <core:CustomData key="aiType" value="new-assistant" />
    </customData>
</GenericTile>
```

2. **在 i18n 文件添加翻译**:
```properties
# i18n.properties
newAssistantTitle=New Assistant
newAssistantSubtitle=Description of new assistant
welcomeTitle_new-assistant=Welcome to New Assistant
welcomeMessage_new-assistant=I can help you with...
```

3. **在后端添加 App ID 映射**（见后端说明文档）

### 添加新页面

1. **创建视图**: `view/NewPage.view.xml`
2. **创建控制器**: `controller/NewPage.controller.js`
3. **在 manifest.json 添加路由**:
```json
{
    "routes": [
        {
            "name": "newPage",
            "pattern": "new-page",
            "target": "newPage"
        }
    ],
    "targets": {
        "newPage": {
            "viewName": "NewPage",
            "viewLevel": 2
        }
    }
}
```

### 自定义样式

直接编辑 `css/style.css` 文件，样式会自动应用。

   ```javascript
   this.getView().getModel("chat").getData()
   ```
