# 文件本地极速解析功能实现说明 (原文件上传)

## 功能概述

在 V1.4.3 及以前，项目使用了十分重度的阿里云百炼 OpenAPI 后端上传链路：申请租约 -> OSS直传 -> 轮询解析结果。该链路经常因为各种原因（如 RAM AK/SK 不配置，RAM 权限不足等）导致 `NoPermission 403` 或者 `CONFIG_ERROR`。
此外，之前的 npm dependencies 非常重，安装时经常阻塞挂起。

为彻底解决这些环境绑定依赖的问题，现已将此功能重构为 **完全免费纯前端本地浏览器极速解析架构**。

## 实现的功能

### UI 界面
1. **上传/选择文件按钮**：在输入框左侧添加了回形针图标的上传按钮。
2. **附件预览区域**：选择文件后，在输入框上方显示文件卡片。
3. **文件卡片样式**：
   - 显示文件类型图标（根据扩展名自动匹配）
   - 显示文件名
   - 显示解析中/已就绪状态
   - 删除按钮（X 图标）

### 解析流程
1. 用户点击回形针按钮，选择文件（如 PDF, Word, Excel）。
2. 前端 `onUploadFile()` 触发，并验证文件大小（最大 50MB）和类型扩展名。
3. 调用核心路由 `_parseFileLocally(oAttachment)`。
4. 根据拓展名不同，走不一样的 FileReader 加载：
   - `.pdf`: 懒加载引入 CDN 第三方开源库 pdf.js，抽取提取每页的 textContent 至 `parsedText`。
   - `.docx`: 懒加载引入 CDN 第三方 mammoth.js，将 word document 抽成 raw text。
   - `.xlsx` / `.csv`: 懒加载引入 CDN xlsx.js，将其转译为 CSV 纯文本字符串。
   - `.txt` / `.md` / `.json` / `.xml`: 浏览器自带 API 原生提取纯文本内容。
5. 前后端数据无需轮询。解析通常在 0.5s 到 3s 内完毕。将抽出的巨大文本字符串挂载进该附件 Model 中的 `parsedText` 属性。
6. 卡片显示变为“已在本地解析”。

### 发送逻辑
- 点击发送时，自动获取所有已解析就绪（status==="parsed"）的附件内的 `parsedText`。
- 将这些巨大的纯文档文本包装，与用户的对话串联拼接（如 `[附录文档 xxx.pdf]:\n<文本>`）。
- 将该合成体作为最新的 `content` 发送给后端的 `/api/chat/stream`，此时对后端透明，后端只把它当做一段很长的新 prompt 请求。

## 技术实现优势

- **无需 RAM AK/SK 或任何鉴权**：再也没有阿里云报错烦恼了。
- **保护隐私**：没有把用户的企业原始电子档上传到公共云去，仅仅借用了阿里云 DashScope 去做带有附带大段 prompt 的推理。
- **免安装后端的沉重依赖**：不用再 `npm install multer form-data @alicloud/xxxx`，解决项目 clone 下来拉取经常卡住的问题。

## 支持的文件类型

- PDF: `.pdf` (pdf.js 解析)
- Word: `.docx` (mammoth.js 解析，注：.doc 老格式因无稳定库暂不支持)
- Excel: `.xls`, `.xlsx`, `.csv` (xlsx.js 解析)
- 文本: `.txt`, `.md`, `.json`, `.xml` (原生 FileReader)

## 配置参数

定义于 `Main.controller.js` 中:
```javascript
var FILE_UPLOAD_CONFIG = {
    MAX_FILE_SIZE: 50 * 1024 * 1024,  // 50MB 最大允许选用
    MAX_FILES_PER_SESSION: 5,          // 单次会话最多5个文件
    ALLOWED_EXTENSIONS: ['.pdf', '.docx', '.txt', '.md', '.json', 
                         '.xml', '.csv', '.xlsx', '.xls']
};

// 预定义好的外网 CDN 地址，进行懒加载
var PARSER_LIBS = {
    pdf: "https://cdnjs.cloudflare.com/ajax/libs/pdf.js/2.16.105/pdf.min.js",
    pdfWorker: "https://cdnjs.cloudflare.com/ajax/libs/pdf.js/2.16.105/pdf.worker.min.js",
    mammoth: "https://cdnjs.cloudflare.com/ajax/libs/mammoth/1.4.21/mammoth.browser.min.js",
    xlsx: "https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js"
};
```
