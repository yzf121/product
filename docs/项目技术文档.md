## 1. 项目概述

### 1.1 项目简介

**AI 助手平台**是一个基于 **SAP CAP (Cloud Application Programming)** 框架和 **SAP UI5 Freestyle** 前端技术构建的企业级 AI 智能助手应用。该平台集成了**阿里云百炼（DashScope）** 大语言模型 API，为 SAP 开发人员提供多种 AI 辅助工具。

### 1.2 核心能力

| 功能模块 | 描述 |
|---------|------|
| **ABAP Clean Core 助手** | 帮助将传统 ABAP 代码重构为云就绪代码 |
| **CPI 集成助手** | SAP CPI Integration Suite 开发指导 |
| **功能文档生成** | 自动生成功能规格说明文档 |
| **FSD to TSD 助手 (I)** | 功能设计文档转技术设计文档（实施方向），支持独立 API Key |
| **FSD to TSD 助手 (E)** | 功能设计文档转技术设计文档（增强方向），支持独立 API Key |
| **技术文档生成** | 自动生成技术设计文档 |
| **代码审查助手** | 智能代码质量检查 |
| **单元测试生成** | 自动生成 ABAP 单元测试代码 |
| **流程图生成** | AI 驱动的 Mermaid 流程图/架构图生成工具 |
| **纯前端文件极速解析** | 毫秒级完全依赖用户电脑本身算力解析 PDF/Word/Excel，不依赖任何额外第三方 API |

### 1.3 技术特性

- ✅ **流式响应 (SSE)**: 支持实时流式 AI 响应
- ✅ **多 AI 助手切换**: 支持多个专业领域 AI 助手 + 专用 API Key
- ✅ **会话管理**: 支持多轮对话，智能会话存储策略
- ✅ **纯前端文件解析**: 浏览器内本地解析 PDF/Word/Excel
- ✅ **Markdown 渲染**: 支持富文本、代码高亮显示
- ✅ **国际化**: 支持中文（zh_CN）和英文（en）
- ✅ **响应式设计**: 适配桌面、平板、手机多端设备
- ✅ **SAP BTP 部署**: 支持一键部署到 SAP BTP
- ✅ **端口自动切换**: 开发时自动检测并使用可用端口

## 4. 后端服务（server.js）

### 4.1 架构概述

后端仅负责**轻量级的大模型流式代理转发**，不包含文件解析/上传逻辑。文件解析已全部移至前端浏览器本地完成。

### 4.2 AI 助手类型与专用 Key 映射

```javascript
// AI 类型与应用 ID 的映射
const AI_APP_ID_MAP = {
    'abap-clean-core': process.env.DASHSCOPE_APP_ID_ABAP || process.env.DASHSCOPE_APP_ID,
    'cpi':             process.env.DASHSCOPE_APP_ID_CPI,
    'func-doc':        process.env.DASHSCOPE_APP_ID_FUNC_DOC,
    'fsd2tsd-i':       process.env.DASHSCOPE_APP_ID_FSD2TSD_I,
    'fsd2tsd-e':       process.env.DASHSCOPE_APP_ID_FSD2TSD_E,
    'tech-doc':        process.env.DASHSCOPE_APP_ID_TECH_DOC,
    'code-review':     process.env.DASHSCOPE_APP_ID_CODE_REVIEW,
    'unit-test':       process.env.DASHSCOPE_APP_ID_UNIT_TEST,
    'diagram':         process.env.DASHSCOPE_APP_ID_DIAGRAM
};

// 专用 API Key 映射（没有专用 Key 的使用全局 DASHSCOPE_API_KEY）
const AI_API_KEY_MAP = {
    'fsd2tsd-i': process.env.DASHSCOPE_API_KEY_FSD2TSD_I,
    'fsd2tsd-e': process.env.DASHSCOPE_API_KEY_FSD2TSD_E
};
```

> **说明**: `fsd2tsd-i` 和 `fsd2tsd-e` 助手支持使用独立的 API Key，通过 `getApiKeyByType()` 函数在运行时动态获取。

### 4.3 会话管理策略

```javascript
const SESSION_CONFIG = {
    MAX_ROUNDS: 50,        // 百炼 API 限制：最多 50 轮
    EXPIRE_HOURS: 1,       // 百炼 API 限制：1 小时过期
    FALLBACK_ROUNDS: 10    // 降级时使用的历史轮数
};
```

**混合策略**:
1. 优先使用 `session_id`（云端存储上下文，节省 token）
2. 超过 50 轮或 1 小时后，自动降级到 `messages` 模式
3. 新对话时只发送当前消息

### 4.4 安全配置

- **本地开发**: 无认证（方便调试）
- **云端部署**: XSUAA OAuth2 认证
- API 密钥仅在后端使用，前端不直接暴露

## 5. 前端应用

### 5.1 路由配置

| 路由名称 | 模式 | 目标视图 |
|---------|------|---------| 
| `home` | `""` | Home.view.xml |
| `chat` | `"chat/{aiType}"` | Main.view.xml |
| `diagram` | `"diagram"` | Diagram.view.xml |

### 5.2 首页 (Home)

SAP Fiori Launchpad 风格入口页面，包含 AI 助手磁贴和工具磁贴。

### 5.3 聊天页面 (Main)

核心对话交互界面，支持：
- 双栏布局（左侧对话历史 + 右侧消息区域）
- 流式打字机效果
- Markdown 渲染 + 代码高亮 + 一键复制
- 纯前端本地文件解析（PDF/Word/Excel/TXT/MD/JSON/CSV等）
- 附件预览区域

### 5.4 纯前端文件解析

前端全面取代了所有服务器端文件上传与解析工作。核心流程：

1. 用户选择文件 → `onUploadFile()` → 验证大小（最大 50MB）和类型
2. `_parseFileLocally()` 根据类型路由到不同解析库
3. 解析库通过 CDN 懒加载（pdf.js / mammoth.js / xlsx.js）
4. 解析结果保存在前端内存中（`parsedText` 属性）
5. 发送时拼接到 prompt 一并发送给后端

```javascript
var PARSER_LIBS = {
    pdf: "https://cdnjs.cloudflare.com/ajax/libs/pdf.js/2.16.105/pdf.min.js",
    mammoth: "https://cdnjs.cloudflare.com/ajax/libs/mammoth/1.4.21/mammoth.browser.min.js",
    xlsx: "https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js"
};
```

### 5.5 流程图页面 (Diagram)

AI 驱动的 Mermaid 流程图生成工具，支持 AI 生成、手动编辑、多格式导出（PNG/SVG）、Draw.io 在线编辑。

### 5.6 第三方库

| 库 | 用途 | 加载方式 |
|---|------|---------|
| marked.js | Markdown 解析 | Local（lib/） |
| highlight.js | 代码高亮 | Local（lib/） |
| mermaid.js | 流程图渲染 | 动态加载（lib/） |
| pdf.js / mammoth.js / xlsx.js | 文件解析 | CDN 懒加载 |
| Draw.io Embed | 图表编辑 | iframe |

```bash
DASHSCOPE_APP_ID_CODE_REVIEW=xxxxxxxx

DASHSCOPE_APP_ID_FSD2TSD_I=xxxxxxxx

DASHSCOPE_APP_ID_FSD2TSD_E=xxxxxxxx

```

> ⚠️ `.env` 文件已添加到 `.gitignore`，切勿提交到版本控制！

### 6.2 CDS 配置 (.cdsrc.json)

```json
{
    "requires": { "db": { "kind": "sql" } },
    "server": { "impl": "./srv/server.js" }
}
```

- `server.impl`: 指定自定义服务器入口，使 CDS 使用 `server.js` 实现 SSE 流式响应

### 6.3 MTA 部署配置 (mta.yaml)

**模块 (Modules)**:
- `abap-clean-core-ai-fiori-new-srv`: Node.js 后端（256MB，1 实例，内部路由）
- `comaiassistantaichatapp`: HTML5 前端应用
- `abap-clean-core-ai-fiori-new-app-deployer`: HTML5 部署器
- `abap-clean-core-ai-fiori-new-destination-content`: Destination 配置

**资源 (Resources)**:
- XSUAA 认证服务、Destination 服务、HTML5 应用仓库

### 6.4 安全配置 (xs-security.json)

- 角色集合: `AIChat_User`（部署后需分配给用户）
- OAuth2 重定向 URI: 覆盖 `*.hana.ondemand.com` 和 `*.platform.sapcloud.cn`

### 6.5 应用路由配置 (xs-app.json)

| 规则 | 描述 |
|-----|------|
| `/api/*` | API 请求转发到后端服务（srv-api Destination） |
| `*` | 静态资源从 HTML5 仓库获取 |

## 7. 本地开发

