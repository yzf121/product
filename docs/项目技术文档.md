# 项目技术文档
> 更新日期：`2026-03-06`

## 1. 项目定位

这是一个面向 SAP 开发场景的多助手 AI 平台。当前版本已从 CAP + UI5 全栈结构重构为纯前端 UI5 架构，目标是直接部署到 SAP BTP Work Zone / HTML5 Repo，而不依赖任何自建后端服务。

## 2. 当前架构

```text
UI5 Frontend
  - 多助手聊天
  - Diagram Helper
  - 本地附件解析
  - localStorage 会话历史
  - 运行时配置
        |
        v
DashScope Apps API
```

### 2.1 保留能力

- 多助手入口与路由
- 会话历史与搜索
- 会话置顶、重命名、删除
- 编辑并重新提交最后一条用户消息
- 前端附件解析并注入上下文
- Diagram Helper / Mermaid / Draw.io
- 本地持久化与恢复

### 2.2 删除的运行时依赖

- CAP 服务
- Express SSE 网关
- `/api/chat/stream`
- Cloud Foundry Node.js 运行模块
- `.env` / `cf set-env` 的后端 AI 配置方式

## 3. 关键模块

### 3.1 配置层

文件：

- `app/ai-chat-gui/webapp/config/ai-config.template.js`
- `app/ai-chat-gui/webapp/service/AIConfig.js`

职责：

- 读取 `window.__AI_CHAT_CONFIG__`
- 合并浏览器本地覆盖配置
- 输出每个 `aiType` 的最终 `appId` / `apiKey`
- 为首页设置弹窗提供编辑模型

### 3.2 DashScope 客户端

文件：

- `app/ai-chat-gui/webapp/service/DashScopeClient.js`

职责：

- 组装 DashScope Apps API 请求
- 直接处理 SSE 流
- 标准化上游错误
- 支持 `session_id` 与 `messages` 两种模式

### 3.3 聊天页

文件：

- `app/ai-chat-gui/webapp/controller/Main.controller.js`

职责：

- 管理多会话状态
- 注入附件上下文
- 通过 `DashScopeClient.streamChat()` 获取流式响应
- 持久化会话到 `localStorage`

### 3.4 图表页

文件：

- `app/ai-chat-gui/webapp/controller/Diagram.controller.js`

职责：

- 调用 Diagram 专属助手生成 Mermaid
- 渲染预览
- 导出 PNG/SVG
- 打开 Draw.io 进行二次编辑

## 4. 运行时配置策略

配置来源优先级：

1. `config/ai-config.js`
2. 首页设置弹窗保存的浏览器本地覆盖配置

支持按助手拆分：

- `defaultAppId`
- `defaultApiKey`
- `appIds[aiType]`
- `apiKeys[aiType]`

因此可以做到：

- 默认所有助手共用一套配置
- 只有个别助手使用独立 App ID
- 只有个别助手使用独立 API Key

## 5. 本地开发与部署

### 5.1 本地开发

命令：

```bash
npm run dev
```

本地使用 UI5 开发服务器，不再启动 CDS。

### 5.2 BTP 部署

MTA 仅包含：

- `html5` 前端模块
- `html5-apps-repo`
- `destination`
- `xsuaa`

不再包含 Node.js `srv` 模块。

## 6. 安全与边界

当前纯前端方案意味着：

- API Key 会存在于浏览器运行时配置中
- 更适合受控内部场景
- 若需更强密钥保护，应改用企业代理层或受控 API 网关

这属于前端直连方案的天然边界，不是当前代码缺陷。

## 7. 已知技术取舍

- 聊天和图表继续使用 SSE，保持原有交互体验
- 附件解析仍在本地完成，不引入后端文件链路
- 历史会话继续存储在浏览器 `localStorage`
- 配置也可保存在浏览器本地，换浏览器或清缓存后需要重新配置

## 8. 验证建议

至少执行：

```bash
npm run verify
```

并手工验证：

- 首页设置可保存并再次读取
- 各助手可正常聊天
- 会话历史刷新后能恢复
- Diagram Helper 可生成 Mermaid
- Draw.io 弹窗可打开并导出
