# 项目技术文档

> 项目：`abap-clean-core-ai-fiori-new`  
> 版本：`v1.4.3`  
> 更新日期：`2026-03-05`

## 1. 项目定位

该项目是一个面向 SAP 开发场景的 AI 助手平台：

- 后端：CAP + Express，自定义 SSE 网关
- 前端：SAP UI5 Freestyle，多助手入口 + 聊天 + Diagram Helper
- 外部 AI：阿里云 DashScope Apps API

当前架构中，文件上传解析已从后端迁到浏览器本地。

## 2. 业务能力与 AI 类型

| AI 类型 (`aiType`) | 主要用途 |
| --- | --- |
| `abap-clean-core` | ABAP Clean Core 迁移/规范建议 |
| `cpi` | SAP CPI 集成开发问答 |
| `func-doc` | 功能文档生成 |
| `fsd2tsd-i` | FSD -> TSD（Implementation） |
| `fsd2tsd-e` | FSD -> TSD（Enhancement） |
| `tech-doc` | 技术文档生成 |
| `code-review` | 代码审查 |
| `unit-test` | 单元测试生成 |
| `diagram` | Mermaid 图生成（Diagram Helper） |

说明：`fsd2tsd-i` 与 `fsd2tsd-e` 支持专用 API Key，其他类型默认走全局 Key。

## 3. 架构与请求链路

```text
UI5 (app/ai-chat-gui)
  -> POST /api/chat/stream
CAP bootstrap (srv/server.js)
  -> DashScope /api/v1/apps/{appId}/completion
```

部署在 BTP 时：

- 前端静态资源：`html5-apps-repo`
- 鉴权：`xsuaa`
- 路由：`destination` + `xs-app.json`

## 4. 后端实现（`srv/server.js`）

### 4.1 主要职责

- 提供 `POST /api/chat/stream` 流式接口
- 根据 `aiType` 选择 App ID / API Key
- 维护超时、异常、客户端断连处理
- 处理请求体大小限制（默认 `20mb`）
- 处理 CORS 预检（`OPTIONS /api/chat/stream`）

### 4.2 会话策略

前后端一致配置：

- 最大轮次：`50`
- 过期时长：`1 小时`
- 降级历史：最近 `10` 轮

策略：

1. 有 `sessionId` 时优先走云端会话。
2. `sessionId` 超轮次或过期后，降级为本地 `messages`。
3. 新会话仅发送当前消息。

### 4.3 备用非流式接口

`chat-service.cds/js` 提供 `sendMessage` action（`/api/chat/sendMessage`），用于非流式备用场景。

### 4.4 端口策略

- 若未显式设置 `PORT`，启动时自动检测 `4004` 起的可用端口。
- 若设置了 `PORT`，直接使用指定端口。

## 5. 前端实现（`app/ai-chat-gui/webapp`）

### 5.1 路由

| 路由 | 目标 |
| --- | --- |
| `""` | `Home.view.xml` |
| `"chat/{aiType}"` | `Main.view.xml` |
| `"diagram"` | `Diagram.view.xml` |

### 5.2 聊天页（`Main.controller.js`）

核心能力：

- 流式渲染消息
- 发送中可暂停（再次点击发送按钮）
- Markdown 渲染 + 代码高亮 + 复制按钮
- 对话按 `aiType` 分类存储
- 会话历史持久化到 `localStorage`

本地存储约束（`Component.js`）：

- key：`ai_chat_conversations`
- 最多保存：`100` 个对话
- 超配额时自动裁剪并提示

### 5.3 附件与上下文拼接

当前逻辑：

1. 选择文件后先在浏览器本地解析。
2. 解析成功的附件在发送时提取文本并拼到 prompt。
3. 发送后已就绪附件从当前“待发送区”移除。

限制参数：

- 单文件上限：`50MB`
- 单会话最多附件：`5`

已实现解析：`txt/md/json/csv/xml/pdf/docx/xlsx/xls`。  
未实现解析（但扩展名允许选择）：`doc/ppt/pptx`。

### 5.4 Diagram Helper（`Diagram.controller.js`）

能力：

- 调用 `aiType=diagram` 生成 Mermaid
- 提取/修复 Mermaid 代码块
- 预览与源码双视图
- 缩放/拖拽查看
- 导出 PNG/SVG、复制图片
- 打开 Draw.io 嵌入编辑

### 5.5 国际化

- 默认：`i18n.properties`
- 英文：`i18n_en.properties`
- 中文：`i18n_zh_CN.properties`

## 6. 配置说明

### 6.1 根目录 `package.json`

关键脚本：

| 脚本 | 实际命令 |
| --- | --- |
| `dev` | `cds watch --open ai-chat-gui/webapp/index.html?...` |
| `start` | `cds-serve` |
| `build` | `rimraf resources mta_archives && mbt build --mtar archive` |
| `deploy` | `cf deploy mta_archives/archive.mtar --retries 1` |
| `undeploy` | `cf undeploy abap-clean-core-ai-fiori-new ...` |

### 6.2 `.cdsrc.json`

- 使用 `srv/server.js` 作为 CAP server 实现。
- `db.kind=sql`；项目当前未使用业务持久化表。

### 6.3 `mta.yaml`

模块：

- `abap-clean-core-ai-fiori-new-srv`（Node.js 服务，路径 `gen/srv`）
- `comaiassistantaichatapp`（HTML5 前端构建）
- `abap-clean-core-ai-fiori-new-app-deployer`
- `abap-clean-core-ai-fiori-new-destination-content`

资源：

- `abap-clean-core-ai-fiori-new-auth`（XSUAA）
- `abap-clean-core-ai-fiori-new-destination`
- `abap-clean-core-ai-fiori-new-html5-repo-host`

### 6.4 `xs-security.json`

- 角色集合：`AIChat_User`
- scope：`$XSAPPNAME.user`
- 支持 `hana.ondemand.com` 与 `platform.sapcloud.cn` 域下重定向

### 6.5 `app/ai-chat-gui/xs-app.json`

- `/api/*` -> destination `srv-api`（`authenticationType: xsuaa`）
- 其余静态资源 -> `html5-apps-repo-rt`

## 7. 运行与排查

### 7.1 本地运行

```bash
npm install
npm run dev
```

默认入口：`http://localhost:4004/ai-chat-gui/webapp/index.html`

### 7.2 常见排查点

- AI 返回配置错误：检查 `.env` 或 `cf env`
- 流式中断：检查网络与上游超时（后端超时默认 60 秒）
- 无法访问应用：确认已分配 `AIChat_User`
- 附件解析失败：确认文件类型在已实现解析列表内

## 8. 已知技术债

- `Main.controller.js` 文件体量较大，后续建议按会话/渲染/附件拆分模块。
- 文件选择扩展名与实际解析能力存在差异（`doc/ppt/pptx`）。
- 目前对话仅存浏览器本地，尚无服务端会话同步。
