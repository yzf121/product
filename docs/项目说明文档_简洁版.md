# AI 助手平台 - 项目简介

> **更新日期**: 2025-01-23  
> **版本**: 1.4.3

本项目是一个基于 **SAP Cloud Application Programming (CAP) Node.js** 框架和 **SAP UI5 Freestyle** 前端技术构建的企业级 AI 辅助平台，集成了**阿里云百炼 (DashScope)** 大模型服务。

**核心能力：**
平台提供 **4 个专业 AI 助手**（ABAP Clean Core、SAP CPI、功能文档、技术文档）和 **3 个开发工具**（代码审查、单元测试生成、Mermaid 流程/架构图生成）。系统支持多轮对话、Markdown 富文本渲染、代码高亮、历史会话管理及**文件上传**功能。

**前端本地极速文件解析：**
前端全面取代所有沉重的服务器文件上传与解析工作。**聊天界面**采用响应式双栏布局，支持纯前端毫秒级浏览器内本地解析（自动懒加载拉取 CDN 下的 PDF/Word/Excel 免费开源库分析，并在解析后无缝附带给 AI 当上下文）。支持 PDF、Word、Excel、TXT、Markdown、JSON、CSV 等十余种格式；并提供包含 Markdown 渲染、代码一键复制的代码助手。**流程图工具**提供左右分屏视图，支持生成及 Draw.io 在线编辑。

**技术架构与 AI 调用：**
后端 (`srv/server.js`) 作为安全代理网关，由于文件解析全部放在了前端，因此彻底移除了卡脖子的阿里云 OSS 和百炼租赁 SDK 及诸多繁复依赖，后端仅轻量暴露并保护大模型转发网关 `/api/chat/stream`，安全承接纯文本（含已在前端解出内容的附件文本）流。系统采用混合会话策略，并有完整的 Token 经济性保障。
