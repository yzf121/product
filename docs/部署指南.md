# 部署指南（SAP BTP / Cloud Foundry）

> 更新日期：`2026-03-05`  
> MTA ID：`abap-clean-core-ai-fiori-new`

本文档以当前 `mta.yaml`、`package.json`、`xs-security.json` 为准。

## 1. 前置条件

### 1.1 工具要求

| 工具 | 建议版本 | 说明 |
| --- | --- | --- |
| Node.js | `>=18` | 与 `package.json` engines 保持一致 |
| npm | `>=8` | 执行脚本/安装依赖 |
| Cloud Foundry CLI | 最新稳定版 | 部署、日志、环境变量管理 |
| CF MultiApps 插件 | 最新稳定版 | `cf deploy` / `cf undeploy` |
| mbt | `>=1.2.29` | 已在 devDependencies 中声明 |
| GNU make | 可执行命令 `make` | `mbt build` 必需依赖 |

### 1.2 本地检查

```bash
node --version
npm --version
cf --version
cf plugins
npm run doctor
```

若 `plugins` 中无 `multiapps`，执行：

```bash
cf install-plugin multiapps
```

## 2. 首次部署流程

### 2.1 安装依赖与构建

```bash
npm install
npm run build
```

产物：`mta_archives/archive.mtar`

### 2.2 登录并指定目标空间

```bash
cf login -a <api-endpoint>
cf target -o <org> -s <space>
```

中国区常见 endpoint 示例：`https://api.cf.cn40.hana.ondemand.com`

### 2.3 部署 MTAR

```bash
npm run deploy
```

等效命令：

```bash
cf deploy mta_archives/archive.mtar --retries 1
```

### 2.4 部署后设置环境变量

至少设置以下变量（后端应用：`abap-clean-core-ai-fiori-new-srv`）：

```bash
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_API_KEY <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID <value>
```

按需配置助手专属 App ID / Key：

```bash
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_ABAP <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_CPI <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_FUNC_DOC <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_FSD2TSD_I <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_API_KEY_FSD2TSD_I <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_FSD2TSD_E <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_API_KEY_FSD2TSD_E <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_TECH_DOC <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_CODE_REVIEW <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_UNIT_TEST <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_DIAGRAM <value>
```

设置后必须重启：

```bash
cf restage abap-clean-core-ai-fiori-new-srv
```

### 2.5 权限与可见性

在 BTP Cockpit 为用户分配角色集合：`AIChat_User`。

如果通过 Work Zone 暴露应用：

1. 进入 Content Manager。
2. 找到 `com.ai.assistant.aichatapp`。
3. 发布到对应站点与角色。

## 3. 验证部署

```bash
cf apps
cf services
cf env abap-clean-core-ai-fiori-new-srv
cf logs abap-clean-core-ai-fiori-new-srv --recent
```

按日志筛选 AI 配置（Windows）：

```bash
cf logs abap-clean-core-ai-fiori-new-srv --recent | findstr "[AI]"
```

按日志筛选 AI 配置（Linux/macOS）：

```bash
cf logs abap-clean-core-ai-fiori-new-srv --recent | grep "\[AI\]"
```

检查项：

- `/api/chat/stream` 请求返回 `text/event-stream`
- 前端打开后无 `401/403`（已分配 `AIChat_User`）
- 至少一个 `DASHSCOPE_APP_ID*` 生效

## 4. 升级与回滚

### 4.1 常规升级

```bash
npm run build
npm run deploy
```

### 4.2 卸载

```bash
npm run undeploy
```

等效命令：

```bash
cf undeploy abap-clean-core-ai-fiori-new --delete-services --delete-service-keys --delete-service-brokers
```

## 5. 常见问题

### 5.1 AI 返回“配置不完整”

- 检查：`cf env abap-clean-core-ai-fiori-new-srv`
- 确认已执行：`cf restage abap-clean-core-ai-fiori-new-srv`

### 5.2 可进入 Work Zone 但接口 401/403

- 检查用户是否分配 `AIChat_User`
- 检查 `xs-app.json` 中 `/api/*` 是否走 `srv-api` destination

### 5.3 构建报错（前端依赖异常）

```bash
cd app/ai-chat-gui
npm install
npm run build
cd ../..
npm run build
```

### 5.4 本地端口冲突

- 默认端口 `4004`，代码会自动尝试下一个可用端口。
- 如需固定端口：`PORT=5000 npm run dev`（PowerShell 可用 `$env:PORT=5000; npm run dev`）
