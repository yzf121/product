# 部署指南（SAP BTP / Work Zone / Pure Frontend）
> 更新日期：`2026-03-06`  
> MTA ID：`abap-clean-core-ai-fiori-new`

本文档以当前纯前端版本为准。应用部署后只包含 HTML5 前端、HTML5 Repo、Destination、XSUAA，不再需要 CAP/Node.js 后端模块。

## 1. 前置条件

### 1.1 工具要求

| 工具 | 建议版本 | 说明 |
| --- | --- | --- |
| Node.js | `>=18` | 与根 `package.json` 一致 |
| npm | `>=8` | 安装依赖、执行脚本 |
| Cloud Foundry CLI | 最新稳定版 | 部署、查看服务 |
| CF MultiApps 插件 | 最新稳定版 | `cf deploy` / `cf undeploy` |
| mbt | `>=1.2.29` | 生成 MTAR |
| GNU make | 可执行 `make` | `mbt build` 依赖 |

### 1.2 本地检查

```bash
node --version
npm --version
cf --version
cf plugins
npm run doctor
```

若 `cf plugins` 中无 `multiapps`，执行：

```bash
cf install-plugin multiapps
```

## 2. 配置方式

### 2.1 推荐方式：应用内运行时配置

部署后首次进入应用，点击首页右上角“设置”，填写：

- `Default API Key`
- `Default App ID`
- 按助手区分的 `App IDs (JSON)`
- 按助手区分的 `API Keys (JSON)`

该方式将配置存入当前浏览器的 `localStorage`，适合 Work Zone 内部使用、无需改包。

### 2.2 文件方式：外部化 `ai-config.js`

在打包前编辑：

`app/ai-chat-gui/webapp/config/ai-config.js`

模板参考：

`app/ai-chat-gui/webapp/config/ai-config.template.js`

最小示例：

```js
window.__AI_CHAT_CONFIG__ = {
  endpoint: "https://dashscope.aliyuncs.com/api/v1",
  timeoutMs: 60000,
  defaultAppId: "your-default-app-id",
  defaultApiKey: "your-default-api-key"
};
```

## 3. 构建与部署

### 3.1 安装依赖并构建

```bash
npm install
npm run build
```

产物：

```text
mta_archives/archive.mtar
```

### 3.2 登录并指定目标空间

```bash
cf login -a <api-endpoint>
cf target -o <org> -s <space>
```

中国区常见 endpoint 示例：

```text
https://api.cf.cn40.hana.ondemand.com
```

### 3.3 部署 MTAR

```bash
npm run deploy
```

等效命令：

```bash
cf deploy mta_archives/archive.mtar --retries 1
```

## 4. Work Zone 发布

1. 进入 BTP Work Zone Content Manager。
2. 找到应用 `com.ai.assistant.aichatapp`。
3. 发布到目标站点。
4. 将角色集合 `AIChat_User` 分配给目标用户。

## 5. 验证部署

```bash
cf apps
cf services
```

验证项：

- 应用能在 Work Zone 中打开
- 首页右上角“设置”可保存运行时配置
- 聊天页和 Diagram Helper 能直接返回流式内容
- 浏览器网络请求直接访问 `https://dashscope.aliyuncs.com/api/v1/...`

## 6. 常见问题

### 6.1 首页提示“配置缺失”

- 先打开应用设置，填写 `API Key` 与 `App ID`
- 或在打包前正确维护 `config/ai-config.js`

### 6.2 Work Zone 能打开应用，但 AI 无返回

- 打开浏览器开发者工具，确认 DashScope 请求是否返回 4xx/5xx
- 核对当前浏览器是否已保存本地覆盖配置
- 检查 `App ID` 和 `API Key` 是否匹配对应助手

### 6.3 构建报错

```bash
npm install
npm run verify
```

### 6.4 `mbt build` / `make not found`

先执行：

```bash
npm run doctor
```

Windows 可安装 GNU make：

```bash
winget install --id GnuWin32.Make --exact
```
