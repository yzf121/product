# 部署指南

> **目标平台**: SAP BTP / Cloud Foundry  
> **更新日期**: 2026-03-04

---

## 1. 环境准备

### 1.1 必需工具

| 工具 | 版本要求 | 安装方式 |
|-----|---------|---------| 
| Node.js | >= 18.0.0 | [nodejs.org](https://nodejs.org/) |
| Cloud Foundry CLI | 最新版 | [安装指南](https://docs.cloudfoundry.org/cf-cli/install-go-cli.html) |
| MultiApps CF CLI Plugin | 最新版 | `cf install-plugin multiapps` |
| MTA Build Tool | >= 1.2.29 | 已包含在 devDependencies 中 |

### 1.2 验证安装

```bash
node --version    # >= v18.x.x
npm --version     # >= 8.x.x
cf --version      # cf version 8.x.x
```

## 2. 本地开发

```bash
# 1. 安装依赖
npm install

# 2. 创建 .env 文件，填写 API 密钥（参考 项目技术文档.md）

# 3. 启动开发服务器
npm run dev
```

服务器将在 `http://localhost:4004` 启动（端口被占用会自动切换）。  
应用入口：`http://localhost:4004/ai-chat-gui/webapp/index.html`

---

## 3. 构建与部署

### 3.1 登录 Cloud Foundry

```bash
cf login -a https://api.cf.cn40.hana.ondemand.com
# 或使用 SSO
cf login -a https://api.cf.cn40.hana.ondemand.com --sso

# 选择目标空间
cf target -o <org> -s <space>
```

### 3.2 构建 MTA 包

```bash
npm run build
```

等效命令: `rimraf resources mta_archives && mbt build --mtar archive`

生成产物: `mta_archives/archive.mtar`

### 3.3 部署

```bash
npm run deploy
```

等效命令: `cf deploy mta_archives/archive.mtar --retries 1`

部署将自动创建以下服务实例：
- `abap-clean-core-ai-fiori-new-auth` (XSUAA)
- `abap-clean-core-ai-fiori-new-destination` (Destination)
- `abap-clean-core-ai-fiori-new-html5-repo-host` (HTML5 Repository)

## 4. 部署后配置

### 4.1 设置运行时环境变量

**必填（AI 对话功能）**:
```bash
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_API_KEY <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID <value>
```

**可选（各 AI 助手，按需配置）**:
```bash
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_ABAP <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_CPI <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_FUNC_DOC <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_TECH_DOC <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_CODE_REVIEW <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_UNIT_TEST <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_DIAGRAM <value>

# FSD to TSD 助手（支持独立 API Key）
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_FSD2TSD_I <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_API_KEY_FSD2TSD_I <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_APP_ID_FSD2TSD_E <value>
cf set-env abap-clean-core-ai-fiori-new-srv DASHSCOPE_API_KEY_FSD2TSD_E <value>
```

设置完成后重启应用:
```bash
cf restage abap-clean-core-ai-fiori-new-srv
```

### 4.2 分配用户角色

在 **BTP Cockpit** > **Security** > **Role Collections** 中：
1. 找到 `AIChat_User` 角色集合
2. 添加需要访问应用的用户

### 4.3 Work Zone 内容发布

1. 进入 Work Zone Content Manager
2. 在 HTML5 Apps 中找到应用 `com.ai.assistant.aichatapp`
3. 将其添加到对应的 Content / Role，并发布到站点

## 7. 常见问题

### Q: AI 功能返回错误？
**A**: 检查环境变量是否正确配置: `cf env abap-clean-core-ai-fiori-new-srv`。确认设置后已执行 `cf restage`。

### Q: 用户无法访问应用？
**A**: 在 BTP Cockpit 为用户分配 `AIChat_User` 角色集合，等待几分钟后刷新页面。

### Q: 构建失败？
**A**: 清理后重试:
```bash
cd app/ai-chat-gui && rm -rf node_modules package-lock.json && npm install && cd ../..
npm run build
```

### Q: 本地端口被占用？
**A**: 应用会自动切换到下一个可用端口（4005, 4006...），或手动指定: `PORT=5000 npm run dev`
